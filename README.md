# Leon'un Meyhanesi — QR Menü

Leon'un Meyhanesi (Çeşme) için mobil öncelikli dijital menü. Next.js 16 (App Router) + Tailwind CSS 4.

```bash
npm install
npm run dev   # http://localhost:3000
```

- Menü verisi ve fiyatlar: `src/lib/leon/menu-data.ts`
- Sayfa: `src/app/page.tsx`, logo: `src/components/leon/leon-logo.tsx`
- Kategori fotoğrafları: `public/leon/` (restoranın Instagram hesabından); Kokteyller, Alkolsüz, Shotlar ve İthal İçkiler henüz temsili Unsplash görselleri kullanıyor.
